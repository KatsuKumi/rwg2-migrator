rwg2-migrator

Move your GTNH world to RWG2 Smooth, and keep your base exactly as it is

You choose the chunks to keep. The tool looks for the RWG2 terrain that fits around them best, shows it to you on a map, builds the new world in a working copy and swaps it in only when you say so. Your current world is kept as the backup.

One rule: close the game or stop the server before you start, and keep it closed until Apply is done.

        No config folder: the search uses GTNH's default RWG2 settings. If you have the config folder of your server or game instance, pick it on the World screen.

        Tick "I accept the Minecraft EULA" on the World screen first: the search runs the official GTNH server pack.

        Excellent match found: you can stop now and keep the best so far.

        Recommended: the best-ranked excellent match or, if there is none, the best-ranked one whose border is not rough (none if every border is rough). Excellent: most steps at the border 1 block or less, at most 10% over 10 blocks, and at least 70% of the edge looks like your base.

            Applying…

            Your world now uses RWG2 Smooth

            First rule: after every GTNH update, open this tool and run Verify, or set these 4 lines again in the "expert / worldgen migration" section of config/rwg2.cfg

            A GTNH update replaces the config folder. Without these lines every new chunk beyond the generated area uses no offset, and cliffs appear about 8 chunks out, which cannot be undone for chunks already generated.

            The 4 lines go inside that section, between its braces, in place of the lines with the same names.
